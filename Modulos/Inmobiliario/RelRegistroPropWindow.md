# <a id="top"></a> <img src="../../Media/RegistroPropiedad.png" alt="RegistroPropiedad" height="30"> Registros de la Propiedad

**Registros de la Propiedad** es el catálogo de registros que puedes indicar en la cabecera de una [finca registral](FincaRegistralWindow.html#cabecera).

> Este catálogo es global: no está filtrado por empresa.

## Cómo se abre

Desde la ventana principal, pestaña **Inmobiliario**, menú **Tablas**, opción **Registros de la Propiedad**.

---

## La lista

| Columna | Descripción |
| --- | --- |
| **Código** | Código del registro. *Obligatorio,* en mayúsculas, sin espacios en blanco, y solo con letras, números, puntos, guiones y barras. No puede repetirse. |
| **Nombre** | Nombre del registro. *Obligatorio.* |
| **Número** | Número del registro. *Obligatorio,* no puede repetirse dentro del mismo municipio. |
| **Municipio INE** | Municipio del registro, mediante buscador. *Obligatorio.* |

---

## Avisos habituales

| Aviso | Causa |
| --- | --- |
| *"El código (Registro propiedad) debe tener valor." / "...no puede tener espacios en blanco." / "...solo puede tener caracteres [A-Z], [0-9], '.', '-' y '/'."* | El código introducido no es válido. |
| *"El código de registro ya existe."* | Ya hay un registro con ese código. |
| *"Nombre registro obligatorio"* | Falta el nombre del registro. |
| *"Municipio INE obligatorio"* | Falta el municipio. |
| *"El número de registro es obligatorio."* | Falta el número del registro. |
| *"El registro nº {número} del municipio {municipio} ya tiene asignado el código {código}."* | Ya existe otro registro con ese mismo número en ese municipio. |
