# <a id="top"></a> <img src="../../Media/Entidad.png" alt="Entidad" height="30"> Tipos de pago de contratos inmobiliarios

**Tipos de pago** es el catálogo de tipos de pago que puedes usar en las líneas de [Formas de pago](RelEntidadPagoWindow.html#líneas-de-la-forma-de-pago) y en el plan de pagos de la sección [Pago y Plan](EntidadContratoWindow.html#pago-y-plan) de un contrato.

> Este catálogo es global: no está filtrado por empresa.

## Cómo se abre

Desde la ventana principal, pestaña **Inmobiliario**, menú **Tablas**, opción **Tipos de pago**.

---

## La lista

| Columna | Descripción |
| --- | --- |
| **Código** | Código del tipo de pago, en mayúsculas. |
| **Descripción** | Descripción del tipo de pago. |
| **Periodicidad** | Periodicidad de los plazos de este tipo de pago, de una lista de valores configurada en la aplicación. |
| **Facturar** | Casilla que indica si este tipo de pago genera factura. |

> Esta ventana no comprueba el formato del código ni exige la descripción: revisa los datos antes de guardar, ya que un código repetido no se detecta hasta grabar.
