# <a id="top"></a> <img src="../../Media/TipoSuperficie.png" alt="TipoSuperficie" height="30"> Tipos de superficie

**Tipos de superficie** es el catálogo de tipos que puedes usar en las [superficies de una entidad](EntidadWindow.html#superficies), en la superficie de una [finca registral](FincaRegistralWindow.html#superficie) o [catastral](FincaCatastralWindow.html#superficie), y en el [informe de entidades](EntidadRptWindow.html#ejecutar-generar-el-informe).

> Este catálogo es global: no está filtrado por empresa.

## Cómo se abre

Desde la ventana principal, pestaña **Inmobiliario**, menú **Tablas**, opción **Tipos de superficie**.

---

## La lista

| Columna | Descripción |
| --- | --- |
| **Código** | Código del tipo de superficie. *Obligatorio.* A diferencia de otros catálogos de esta sección, aquí no se fuerza a mayúsculas. |
| **Descripción** | Descripción del tipo. *Obligatoria.* |
| **Clasificación** | Clasificación de la superficie, de una lista de valores configurada en la aplicación. |
| **Unidad de medida** | Unidad de medida por defecto de este tipo de superficie, mediante buscador. *Obligatoria y debe existir.* |

---

## Avisos habituales

| Aviso | Causa |
| --- | --- |
| *"El código debe tener valor." / "...no puede tener espacios en blanco." / "...solo puede tener caracteres [A-Z], [0-9], '.', '-' y '/'."* | El código introducido no es válido. |
| *"Falta descripción"* | Falta la descripción del tipo. |
| *"La unidad de medida es obligatoria"* | Falta la unidad de medida. |
| *"Unidad de medida inexistente"* | La unidad de medida indicada no existe. |
