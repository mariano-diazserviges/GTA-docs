# <a id="top"></a> <img src="../../Media/TipoEntidad.png" alt="TipoEntidad" height="30"> Tipos de entidad

**Tipos de entidad** es el catálogo de clasificaciones que puedes asignar a una entidad en su campo [Tipo de entidad](EntidadWindow.html#ficha-entidad), y que también sirven para filtrar por nivel de desarrollo en la [lista de entidades](RelEntidadWindow.html#la-lista).

> Este catálogo es global: no está filtrado por empresa.

## Cómo se abre

Desde la ventana principal, pestaña **Inmobiliario**, menú **Tablas**, opción **Tipos de entidad**.

---

## La lista

| Columna | Descripción |
| --- | --- |
| **Código** | Código del tipo de entidad. *Obligatorio,* en mayúsculas, sin espacios en blanco, y solo con letras, números, puntos, guiones y barras. |
| **Descripción** | Descripción del tipo. *Obligatoria.* |
| **Nivel de desarrollo inmobiliario** | Nivel jerárquico del tipo (por ejemplo, suelo, edificio, división, anejo...), de una lista de valores configurada en la aplicación. |

---

## Avisos habituales

| Aviso | Causa |
| --- | --- |
| *"El código debe tener valor." / "...no puede tener espacios en blanco." / "...solo puede tener caracteres [A-Z], [0-9], '.', '-' y '/'."* | El código introducido no es válido. |
| *"La descripción es obligatoria."* | Falta la descripción del tipo. |
