# <a id="top"></a> <img src="../../Media/Entidad.png" alt="Entidad" height="30"> Tipos de entidad comercial

**Tipos de entidad comercial** es el catálogo de clasificaciones comerciales que puedes asignar a una entidad en su campo [Tipo de entidad comercial](EntidadWindow.html#ficha-entidad), con el número habitual de estancias de cada tipo.

> Este catálogo se define por promoción: trabaja siempre sobre la empresa y la referencia activas.

## Cómo se abre

Desde la ventana principal, pestaña **Inmobiliario**, menú **Tablas**, opción **Tipos de entidad comercial**.

---

## La lista

| Columna | Descripción |
| --- | --- |
| **Código** | Código del tipo de entidad comercial. *Obligatorio,* en mayúsculas, sin espacios en blanco, y solo con letras, números, puntos, guiones y barras. |
| **Descripción** | Descripción del tipo. |
| **Dormitorios** / **Baños** / **Terrazas** / **Secaderos** / **Salones** / **Comedores** / **Vestíbulos** | Número habitual de cada estancia para este tipo de entidad. |

---

## Avisos habituales

| Aviso | Causa |
| --- | --- |
| *"El código (Tipo entidad comercial) debe tener valor." / "...no puede tener espacios en blanco." / "...solo puede tener caracteres [A-Z], [0-9], '.', '-' y '/'."* | El código introducido no es válido. |
| *"Debe especificar una referencia en ejecución antes de añadir un tipo entidad comercial."* | Se intentó añadir un tipo sin tener una promoción activa. |
