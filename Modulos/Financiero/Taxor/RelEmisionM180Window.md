# <a id="top"></a> <img src="../../../Media/TaxorLiqM115.png" alt="TaxorLiqM115" height="40"> Modelo 180 (TAXOR)

## Cómo se abre

Desde la ventana principal, pestaña **Financiero**, grupo **TAXOR**, despliega el botón <img src="../../../Media/TaxorLiqM115.png" alt="Modelo 115" height="20"> **Modelo 115** y elige **Modelo 180**.

---

## La lista

Una fila por empresa y ejercicio:

| Columna | Descripción |
| --- | --- |
| **Empresa** / **Colaborador** | Empresa y colaborador/asesor TAXOR. |
| **Persona de contacto** | Persona de contacto de la declaración. |
| **Complementaria** / **Nº complementaria** / **Sustitutiva** | Datos de declaraciones complementarias o sustitutivas de una presentación previa. |
| **Fecha emisión** / **Hora emisión** | Fecha y hora en que se calculó la declaración. |
| **CSV** | Código Seguro de Verificación de la declaración presentada. |
| **Definitiva** | Indica si la declaración es definitiva. |
| **Fecha y hora presentación AEAT** / **Descripción error AEAT** | Datos de la presentación en la AEAT. |

> Este modelo no tiene un importe único que totalizar: la fila de totales solo indica el número de declaraciones mostradas.

El estado de cada fila se colorea igual que en [Liquidación de IVA](RelTaxorLiqIvaWindow.html#estado-de-la-declaración) (Sin datos, No presenta, Borrador, Definitiva, Presentada).

---

## Actualizar y comprobar los datos

Esta ventana se recalcula junto con el resto de liquidaciones periódicas, y comparte el mismo mecanismo de verificación de la presentación en la AEAT. Consulta [Actualizar las liquidaciones](RelTaxorLiqResumenWindow.html#actualizar-las-liquidaciones), [Ver el justificante en la AEAT](RelTaxorLiqResumenWindow.html#ver-el-justificante-en-la-aeat) y [Comprobar la presentación](RelTaxorLiqResumenWindow.html#comprobar-la-presentación-en-la-aeat) en el Resumen de liquidaciones para el detalle completo.
