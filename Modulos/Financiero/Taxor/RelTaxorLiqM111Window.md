## Cómo se abre

Desde la ventana principal, pestaña **Financiero**, grupo **TAXOR**, botón <img src="../../../Media/TaxorLiqM111.png" alt="Modelo 111" height="20"> **Modelo 111**. Al desplegar el botón se accede también al [Modelo 190](#modelo-190-resumen-anual).

---

## Cabecera

| Campo | Descripción |
| --- | --- |
| **Ejercicio** / **Periodo** | Ejercicio y periodo de las liquidaciones mostradas. Solo lectura: se controlan desde el [Resumen de liquidaciones](RelTaxorLiqResumenWindow.html#cabecera). |

---

## La lista

Una fila por empresa:

| Columna | Descripción |
| --- | --- |
| **Empresa** / **Colaborador** | Empresa y colaborador/asesor TAXOR. |
| **Total retenciones** | Total de retenciones e ingresos a cuenta del periodo. |
| **Importe declar. anterior** | Importe a deducir de declaraciones anteriores, si es complementaria. |
| **Total a ingresar** | Importe final a ingresar. |
| **Perceptores din. trabajo** / **Base dineraria trabajo** / **Ret. dineraria trabajo** | Perceptores, base y retención de rendimientos dinerarios del trabajo. |
| **Perceptores esp. trabajo** / **Base especie trabajo** / **Ingr. cta. especie trabajo** | Perceptores, base e ingreso a cuenta de retribuciones en especie del trabajo. |
| **Perceptores din. profesional** / **Base dineraria profesional** / **Ret. dineraria profesional** | Perceptores, base y retención de rendimientos dinerarios de actividades profesionales. |
| **Perceptores esp. profesional** / **Base especie profesional** / **Ingr. cta. especie profesional** | Perceptores, base e ingreso a cuenta de retribuciones en especie de actividades profesionales. |
| **Fecha emisión** / **Hora emisión** | Fecha y hora en que se calculó la liquidación. |
| **Tipo abono/adeudo** / **Cuenta domiciliación** | Forma de pago o cobro y cuenta bancaria. |
| **CSV** | Código Seguro de Verificación de la declaración presentada. |
| **Definitiva** | Indica si la declaración es definitiva. |
| **Fecha y hora presentación AEAT** / **Descripción error AEAT** | Datos de la presentación en la AEAT. |

La fila de totales suma los importes de todas las empresas mostradas. El estado de cada fila se colorea igual que en [Liquidación de IVA](RelTaxorLiqIvaWindow.html#estado-de-la-declaración) (Sin datos, No presenta, Borrador, Definitiva, Presentada).

---

## Modelo 190 (resumen anual)

El [Modelo 190](RelEmisionM190Window.html) es el resumen anual de las retenciones de este modelo (declarado una vez al año, con los datos acumulados de los cuatro trimestres del Modelo 111). Se abre desde el mismo botón desplegable de esta ventana.

---

## Actualizar y comprobar los datos

Esta ventana se recalcula junto con el resto de liquidaciones periódicas, y comparte el mismo mecanismo de verificación de la presentación en la AEAT. Consulta [Actualizar las liquidaciones](RelTaxorLiqResumenWindow.html#actualizar-las-liquidaciones), [Ver el justificante en la AEAT](RelTaxorLiqResumenWindow.html#ver-el-justificante-en-la-aeat) y [Comprobar la presentación](RelTaxorLiqResumenWindow.html#comprobar-la-presentación-en-la-aeat) en el Resumen de liquidaciones para el detalle completo.
